# wildberries-mcp

[English](README.md) · **Русский**

> Сервер для покупателя: работает с публичной витриной, аккаунт и токен
> Wildberries не нужны. Если вам нужен **кабинет продавца** (заказы, остатки,
> поставки через официальный Seller API) — это другой инструмент:
> [theYahia/wildberries-mcp](https://github.com/theYahia/wildberries-mcp).

[MCP](https://modelcontextprotocol.io)-сервер, который даёт LLM-агентам
актуальные данные с [Wildberries](https://www.wildberries.ru) и честно
подписывает, что это за данные. Есть поиск с настоящими страницами, сортировкой
и ценовым окном, живые карточки товаров, рейтинг и отзывы по артикулу,
история цен по неделям и юридические данные продавца.

## Зачем ещё один сервер для WB

Большинство парсеров WB тихо отдают не то, что видит покупатель. Этот сервер
построен так, чтобы этого не делать:

| Ловушка | Что делает сервер |
|---|---|
| Поиск отвергает клиентов без антибот-токена WB (HTTP 403/498) | Получает токен коротким заходом headless Chromium и перевыпускает его, когда WB токен отзывает |
| «Текущая цена» берётся из истории цен (это средняя за неделю, часто недельной давности) | Живая цена из того же API карточек, что использует сайт: по каждому размеру, с ценой до скидки и размером скидки |
| Рейтинг и отзывы **склейки** выдаются за рейтинг товара (в склейку бывает объединено 16 разных моделей) | Рейтинг артикула, как на странице товара; рейтинг склейки — в отдельном подписанном поле |
| Новые артикулы не открываются, потому что хосты CDN угадываются по зашитой таблице | Хосты берутся из опубликованной WB карты CDN |
| Подложные ответы антибота (посторонние товары, чужой регион) передаются как данные | Каждый ответ API проверяется на правдоподобие; подозрительный запрашивается повторно, а если не проходит — превращается в ошибку |

В каждом ответе есть `fetched_at` и регион доставки, для которого получены данные.

## Инструменты

| Инструмент | Что возвращает |
|---|---|
| `search_products(query, page, sort, price_min, price_max, limit)` | По 100 товаров на страницу; сортировки `popular` / `rating` / `price_asc` / `price_desc` / `newest` / `benefit`; `total_found`, `has_more`. По каждому товару: цена, цена до скидки, скидка, рейтинг и отзывы (по артикулу), остаток, продавец и его рейтинг, срок доставки (в часах), id склейки, ссылка |
| `get_product(article, include_variants)` | Живое предложение по размерам, остаток, срок доставки; рейтинг артикула и склейки с распределением звёзд; продавец с юрлицом, адресом и ИНН/УНП; характеристики; описание; комплектация; сводка истории цен; остальные артикулы склейки с их живыми ценами |
| `get_price_history(article)` | Средние цены по неделям рядом с живой ценой; минимум, максимум и отклонение текущей цены от них |
| `get_reviews(article, limit, scope, sort, min_rating, max_rating)` | Дата, оценка, текст, плюсы, минусы, купленный вариант, теги покупателя, ответ продавца; `scope=article` или вся склейка; `sort=worst` показывает жалобы первыми |
| `compare_products(articles)` | До 50 артикулов рядом за один запрос |

## Установка

Нужны Python ≥ 3.10 и [uv](https://docs.astral.sh/uv/). При первом запуске
сервер один раз скачивает Chromium для Playwright (около 300 МБ): он нужен для
прохождения антибота.

Claude Code:

```bash
claude mcp add wildberries -- uvx --from git+https://github.com/SZhukovWork/wildberries-mcp wildberries-mcp
```

Любой MCP-клиент (`claude_desktop_config.json`, `.mcp.json` и т. п.):

```json
{
  "mcpServers": {
    "wildberries": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/SZhukovWork/wildberries-mcp", "wildberries-mcp"]
    }
  }
}
```

Из клона репозитория: `uv venv && uv pip install -e . && .venv/bin/wildberries-mcp`.

## Настройка (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `WB_DEST` | авто | Id региона доставки WB. По умолчанию регион определяет сам WB по IP (он указан в каждом ответе). Чтобы данные точно соответствовали вашему пункту выдачи, скопируйте `dest=` из любого запроса `__internal/u-card` в инструментах разработчика браузера на wildberries.ru |
| `WB_PROXY` | — | Прокси для HTTP и браузера, например `http://user:pass@host:3128` |
| `WB_MIN_INTERVAL` | `3.0` | Пауза в секундах между запросами к API сайта (поиск, карточки). WB жёстко троттлит, при меньших значениях приходит 429 |
| `WB_CACHE_DIR` | `~/.cache/wildberries-mcp` | Где хранится антибот-сессия |
| `WB_HEADLESS` | `1` | `0` показывает окно браузера во время получения токена (для отладки) |

## Что означают цифры

- **Цены** — то, что прямо сейчас видит анонимный покупатель в указанном регионе.
  Залогиненный покупатель может видеть цену ниже: WB Кошелёк (около 2 %) и
  персональные скидки.
- **`delivery_eta_hours`** — оценка WB для региона (сайт переводит эти же числа в дату).
- **Рейтинг**: `rating`/`reviews` относятся к артикулу, как на странице товара.
  Поля `group` описывают всю склейку. Распределение звёзд из ленты отзывов может
  охватывать меньше оценок, чем считает карточка, — сервер об этом сообщает.
- **Фото в отзывах**: WB не связывает фото с конкретными отзывами, поэтому число
  фото у отзыва не отдаётся (вместо вводящего в заблуждение нуля).
- **История цен** — средние цены за недели; её последняя точка не является текущей ценой.

## Ограничения

- Неофициальный API: сервер опирается на внутренние эндпоинты сайта, WB может
  изменить их в любой момент. Разбор ответов изолирован в `parse.py` и покрыт
  тестами на записанных ответах.
- WB блокирует многие зарубежные, VPN- и датацентровые IP. Нужен российский
  домашний IP или `WB_PROXY`.
- Поиск ограничен троттлингом WB: сервер выдерживает паузы между запросами и
  при превышении возвращает понятную ошибку, а не крутит повторы.
- Только чтение и только анонимно: без аккаунта, корзины и заказов (см. «Планы»).

## Планы

- **Позже: необязательный режим аккаунта** (выключен по умолчанию). Вход один
  раз в видимом окне браузера — номер телефона и SMS-код не проходят через
  MCP-клиент. Даст ваши персональные цены и точные даты доставки в ваш пункт выдачи.
- **Позже: корзина** — `add_to_cart` / `get_cart` поверх режима аккаунта.
  Оформление заказа, оплата и смена адреса сознательно не входят в планы.

## Разработка

```bash
uv venv && uv pip install -e '.[dev]'
.venv/bin/pytest            # офлайн-тесты на записанных ответах
.venv/bin/pytest -m live    # сквозной тест по MCP stdio против живого WB (нужен российский IP)
```

## Оговорка и благодарности

Проект не связан с Wildberries. Предназначен для личного сравнения цен;
соблюдайте пользовательское соглашение Wildberries и не повышайте частоту
запросов. Идея отдать WB в виде MCP-инструментов подсмотрена у
[shndo1337/wildberries-mcp](https://github.com/shndo1337/wildberries-mcp);
этот проект — самостоятельная реализация.
